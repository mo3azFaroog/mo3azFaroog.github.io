Project Overview

📊 مشروع جديد: Salary Analytics Dashboard | Power BI

سلام عليكم يا جماعة 👋
حبيت أشارككم مشروع جديد قمت به باستخدام Power BI، وهو لوحة تحكم تحليل الرواتب (Salary Analytics Dashboard). هذا المشروع يهدف إلى تقديم رؤى شاملة حول بيانات الرواتب، بما في ذلك توزيع الرواتب، الفروق بين الأقسام، وتحليل الأداء المالي للموظفين.

The Project Journey

عصف ذهني عن البيانات : داتاسيت فيها 10 أعمدة أساسية: Job Title، Experience Years، Education Level، Skills Count، Industry، Company Size، Location، Remote Work، Certifications، وSalary.

🔹 الخطوات اللي مشيت فيها

1️⃣ نظّفت البيانات وجهزتها في Power Query (توحيد الأعمدة، التعامل مع القيم الناقصة)

I used Power Query to clean and transform the datasets, handle data quality issues, review data types, and prepare the tables for analysis.

2️⃣ بنيت Calculated Columns زي تصنيف مستوى الخبرة، وSkills Density (معدل المهارات بالنسبة لسنوات الخبرة)

I designed a structured Data Model connecting sales, customers, products, resellers, employees, and territory data while establishing the appropriate relationships between tables.

3️⃣ كتبت DAX Measures للمتوسطات (Average Salary, Median Salary, Employee Count... إلخ)

4️⃣ صممت الداشبورد على 4 صفحات:

  • • Overview
  • • Salary Insights (تعليم، خبرة، صناعة، نمط العمل)
  • • Company & Location Analysis (حجم الشركة، الدول، الشهادات)
  • • Location & Work Arrangement (توزيع جغرافي + نمط العمل)

    • 🔹 أهم الاكتشافات

  • ✅ الخبرة بتزيد الراتب، بس التشتت بيكبر كل ما زادت السنين — يعني عوامل تانية (زي الصناعة والمهارات) بتلعب دور أكبر مع الوقت
  • ✅ التعليم العالي (PhD/Master) بيرفع متوسط الراتب بشكل واضح
  • ✅ الشهادات المهنية ليها علاقة مباشرة بزيادة الراتب — كل ما زادت الشهادات، زاد الراتب
  • ✅ حجم الشركة مؤثر جدًا: الشركات الكبيرة (Enterprise) بتدفع أكثر بفارق كبير عن الشركات الصغيرة

الأدوات المستخدمة

  • 🛠️ Power BI - For data modeling, DAX calculations, and dashboard design.
  • 🛠️ Power Query - For data cleaning and transformation.
  • 🛠️ DAX - For creating calculated columns and measures.
  • 🛠️ SQL - For querying and extracting data from databases.

Core Objective & Outcome
